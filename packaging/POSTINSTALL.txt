NexusKVM — after install
========================

1. Log out and log back in (or reboot).
   The installer adds you to the "input" group; a new session is required.

2. Open NexusKVM:
   - PC with keyboard/mouse → "This is the host"
   - Other PC → "Connect to another" (paste the copied code)

3. Closing the window (✕) hides NexusKVM in the system tray; sharing keeps running.
   Use the tray menu → Quit… to stop the service and exit.

4. After pairing, NexusKVM may ask for your password **once** (pkexec) to enable a
   system service so the host/client stays available at the GDM login screen.
   Later logins should not ask again. Host stays host and client stays client.

5. On the host you should see:
   - Socket: OK
   - Daemon: Active
   - A peer when the other PC connects

6. Hotkey to switch PCs (host keyboard):
   Left Alt + Left Ctrl (both left keys), release together.

7. If the other PC does not connect, check the host firewall (ports 5258/tcp and 5259/tcp).
8. Edge crossing uses the InputCapture portal (GNOME/Wayland). Left Alt + Left Ctrl remains as a fallback.
9. Text clipboard syncs over port 5259 when both agents are active.
   The installer opens that port if ufw is active.

Terminal diagnostics:
  nexusctl status
  nexusctl peers
  systemctl status nexuskvm-host.service
  systemctl status nexuskvm-client.service

Detailed logs (app):
  ~/.local/share/io.nexuskvm.app/logs/
    nexuskvm-ui.log   — GUI actions
    nexus-kvmd.log    — host PC
    rkvm-client.log   — client PC
    nexus-agent.log   — local agent
